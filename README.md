# Personal Portfolio - Assignment 1

## Description

This project is a responsive personal portfolio website created
for SWE 363 Web Engineering.

The website introduces me,presents my skills and projects,and
provides a contact form.

## Features

- Responsive design
- About Me section
- Skills section
- Projects section
- Contact form
- Dark/light mode
- Contact form interaction

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub

## Project Structure

assignment-1/

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation is required.
