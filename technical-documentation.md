# Technical Documentation

## Overview

This project is a static responsive personal portfolio website
developed using HTML,CSS,and JavaScript.

## HTML

HTML is used to create the structure of the website.

The website contains:

- Navigation
- Hero section
- About section
- Skills section
- Projects section
- Contact form
- Footer

## CSS

CSS is used for the layout and visual design.

The website uses CSS Grid and Flexbox.

A media query is used to make the website responsive on smaller
screens.

## JavaScript

JavaScript provides interactive features.

The website includes a dark/light theme button and a contact form
interaction.

## Responsive Design

The website adapts to desktop,tablet,and mobile screen sizes.

The project cards appear in two columns on larger screens and one
column on smaller screens.

## Testing

The website was tested by resizing the browser and using Chrome
Developer Tools.
