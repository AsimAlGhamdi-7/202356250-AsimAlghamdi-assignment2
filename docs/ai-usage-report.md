# AI Usage Report

## Tools Used & Use Cases

I used ChatGPT during this assignment.

ChatGPT helped me plan the structure of the portfolio website,
understand responsive design,review HTML and CSS code and improve it,and
suggest JavaScript interactions.

## Benefits & Challenges

Using AI helped me understand some concepts faster and provided
examples that helped me develop the website.

One challenge was that some AI suggestions were more complex than
needed. I reviewed and simplified the code to match the assignment
requirements.

## Learning Outcomes

While completing this assignment,I improved my understanding of
HTML structure,CSS Grid,Flexbox,responsive design,JavaScript
event listeners,and GitHub.

## Responsible Use & Modifications

I reviewed the AI-generated suggestions before using them.

I modified the content,styling,and code to match my own portfolio
and assignment requirements.

I also tested the website manually to make sure the code worked
correctly.
